# 토해내기 (土.土) — Reducer

사진을 그래픽으로 환원하는 단일 HTML 툴. 설치·빌드·의존성 없이 `index.html` 하나로 동작합니다.

**➡️ https://724ch.github.io/tohaenaegi-reducer/**

## 효과 10가지 (체인으로 쌓기)

실루엣 · 포스터화 · 스텐실 · 모자이크 · 그레인 · 스캔라인 · 하프톤 · 타이포 마스크 · 듀오톤 · 글리치

- **체인 파이프라인** — 효과를 드래그로 겹쳐 쌓고 순서를 바꿀 수 있습니다.
- **실루엣** — 이미지 윤곽을 따고 내부를 망점/원본/흑백/단색으로 채우며, 글자가 윤곽을 따라 도는 **글자 궤도**까지. (기본값이 포스터 톤: 하늘색 배경 + 흰 실루엣)
- **🎲 랜덤** — 효과·파라미터·색을 무작위로 굴려 우연의 그래픽을 만듭니다.
- **PDF 내보내기** — 현재 화면을 한 장짜리 인쇄용 PDF로. 표지·출력용.
- PNG 저장, 종이 투명(녹아웃) 지원.

## 사용

`index.html`을 브라우저에서 열고, 사진을 드래그하거나 `⌘V`로 붙여넣으면 됩니다.

## 만든 것

토닷토(土.土) 〈토해내기〉 전시 · 워크숍용 그래픽 도구.
